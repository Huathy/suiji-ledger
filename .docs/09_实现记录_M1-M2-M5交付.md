## 过程中修复的问题（备忘）

1. tsx(esbuild) 不产出 NestJS DI 元数据 → 运行时改为 **ts-node**
2. 模块依赖缺失：Stats/System 模块引入 MonthsModule；AuthModule 设为全局
3. 前后端相对路径层级错误（shared 库应为 4 级 `../`）
4. **seed 数据中文 mojibake**：Git Bash 下 curl 发送的 UTF-8 被控制台转码 → 改用 `scripts/seed-demo.mjs`（Node fetch）
5. 平账页「上月余额」误取当前余额 → 修正为 API 的 `prevBalance`（上一月快照）
6. Service Worker cache-first 导致发版不生效 → SW 缓存版本号 `mr-v2`，**以后每次发版需递增**
