| 需求 | 支持新建分组，并将已有账户按类型归类（对齐钱迹：资金/充值/投资…） |

## 功能

1. **新建分组**：账户页「🗂 新建分组」→ 输入名称创建（分组列表持久化在 settings.groups，空分组也保留）；弹层内可删除**空的自定义分组**
2. **批量归类**：每个账户行前有勾选框 → 选中后出现操作条「已选 N 个账户 → 移入分组…」→ 底部弹层单选已有分组或**就地新建** → 确认后批量更新
3. **编辑表单快选**：添加/编辑账户时，分组输入框下方点选已有分组一键填充
4. 分组重命名（✎ 批量迁移组内账户）此前已实现，与本次能力互补

> 数据说明：分组信息存在账户的 `group` 字段 + settings.groups（自定义分组名单），备份 JSON 已覆盖。

## 使用指引（针对所有者的真实数据）

真实数据在已安装的桌面版里。升级到 v0.3.4 后：账户页 →「🗂 新建分组」建好 资金/充值/投资 → **勾选**要归类的账户 →「移入分组…」批量归入。对应你钱迹截图的归类方案（资金=各银行卡+微信+支付宝+公积金+工资卡；充值=押金房租；投资=股票/住房/理财）几分钟即可完成。「不计入」账户（公积金/住房）勾掉"计入净资产"即可，分组不受影响。
