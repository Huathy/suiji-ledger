## 五、过程问题备忘

1. **备份路径歧义**（最重要）：BackupService 从 `DATABASE_URL` 反推目录，与 main.ts 的 DATA_DIR 解析在某些启动方式下不一致（曾落到 `apps/data`）→ 统一到 `src/env.ts` 单一来源
2. AppModule 全局模块的 provider 必须 **exports** 才能被其它模块注入（BackupService 漏导出导致 DI 失败）
3. electron-builder 裁剪任何名为 node_modules 的目录（含嵌套）→ 运行时依赖目录名用 `deps`
4. Vitest 测试自踩的坑：CSV 列错位（少一个空列导致手续费/优惠券错位）、恢复后条目为新 id——均已修正，**应用代码无缺陷**
