# 实现记录 · 平账按钮定位修复（v0.2.2）

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-24 |
| 产物 | `dist/SuijiLedger-v0.2.2.apk`（versionCode 4，覆盖安装） |
| 起因 | 项目所有者反馈："平账按钮位置都飘了" |

## 排查与修复（共 3 处）

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | **PC 侧栏"＋平账"按钮随页面内容长度飘出屏幕外**（总览页在 900px 高屏上 top=904 看不见） | 侧栏随 `.app-shell` 拉伸到整页高度，底部的按钮被顶出视口 | `.side-nav` 改为 `position: sticky; top: 0; height: 100vh`——按钮永远固定在屏幕左下角（实测 top=714 < 800 ✓） |
| 2 | **手机底部中央"＋平账"凸起按钮位置不稳** | 借用 Vant TabbarItem 图标槽 + 负 margin 的 hack，受 Vant 内部布局影响 | 改为独立 flex 单元格（`.fab-cell` + `.fab`），按钮与标签居中稳定，语义清晰 |
| 3 | **服务端模式升级后白屏**（排查中发现的连带缺陷） | SW 缓存优先策略缓存了旧 index.html，指向已删除的旧 JS 产物 → 404 白屏 | `sw.js` 改为 **HTML 网络优先**（发版即生效，离线回退缓存），仅哈希命名的静态资源缓存优先；缓存版本升 `mr-v3` |

## 验证

- PC 平账页/总览页截图：侧栏按钮固定视口左下 ✓
- 手机 390px 截图：底部中央按钮居中稳定 ✓
- 双端产物重建（dist + dist-mobile + APK v0.2.2）✓

> 备注：手机 390px 窄视口下浏览器截图曾出现水平重复伪影，为截图工具裁剪问题，整页截图确认无重复渲染。

## 追加（v0.2.3）

应用户反馈，手机底部中央「平账」按钮取消凸起效果，改为与其它 Tab 一致的普通平铺样式（Vant 内置 edit 图标 + 文字），五个 Tab 完全等高对齐；点击跳转逻辑并入统一 Tab 切换处理。产物：`dist/SuijiLedger-v0.2.3.apk`（versionCode 5）。
