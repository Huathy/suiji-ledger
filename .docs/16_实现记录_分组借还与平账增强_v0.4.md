## 一、多分组资产页（对齐钱迹布局）

- 分组 = 账户的 `group` 字段（添加/编辑账户时自定义，如 资金/充值/投资），**每组小计 + 点击折叠**（状态本地记忆），按小计降序排列；负债单列一组
- 顶部：净资产大数（**👁 一键隐藏金额**，全局生效）+ 总资产/总负债分列
- 资产概览卡：`N 项资产 | 负债率% | M 项负债` + 负债率进度条
- 账户行显示「不计入」角标（inNetWorth=false）

## 二、借入借出中心（新增 Loan 实体 + /loans 页）

- 模型：`Loan { direction: in(我欠人)/out(人欠我), counterparty, amount, settledAmount, date, dueDate?, note }`
- 账户页顶部 **总借出（别人欠我）/ 总借入（我欠别人）** 卡片（未结清余额合计），点击进借还中心
- 借还中心：借出/借入两组列表（状态角标 待收回/部分收回/已结清）、**收回/还上**（支持部分，累计进度）、删除、新增
- 设计原则：台账只记「谁欠谁」**不直接改账户余额**——钱实际进出仍由平账/调余额体现，两套记录互不干扰（页面有说明）

## 三、平账增强

1. **（批量记录）备注**：月末批量平账生成的自动平账条目，备注默认「（批量记录）」（平账页可自定义，PC/手机都有输入框；自动重算时保留原备注）
2. **单账户随时调余额**：账户详情 →「修改余额」→ 输新余额+备注 → 更新当月快照 + **单独生成一条平账记录**（类型=平账、金额=本次差额），当月恒等式自动重算
3. 月度详情「变动构成」现在能区分：大项（工资等）/ 单独调整（余额调整…）/ 批量平账（（批量记录）），且 Σ条目 ≡ Σ余额变动 恒等成立
