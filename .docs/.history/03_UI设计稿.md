## 1. 设计原则

1. **移动优先**：375~430px 宽为主画布，桌面端居中限宽 480px 呈"手机壳"布局（也可拉伸双栏，P2）。
2. **3 秒记账**：记一笔默认页 = 上次类型 + 键盘聚焦，选分类 → 点保存即完成。
3. **信息密度克制**：列表一屏 8~10 条，层级最多两跳；金额永远是视觉焦点。
4. **对齐钱迹肌肉记忆**：底部五 Tab（明细/图表/➕/资产/我的）、月份横滑、日分组列表、红色支出/绿色收入。
5. 全量**深色模式**，色彩语义不随主题漂移。

| 分类图标色板 | 12 色 | 同 | `#F87171 #FB923C #FBBF24 #34D399 #22D3EE #60A5FA #818CF8 #A78BFA #F472B6 #94A3B8 #4ADE80 #38BDF8` |

### 2.2 字体与字号

- 字体栈：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；数字用 `font-variant-numeric: tabular-nums`（列表金额对齐）。
- 字号：页面大标题 20/600；卡片标题 16/600；正文 14；辅助 12；金额（列表）16/600；金额（记一笔大数）40/700。

### 2.3 布局与控件

- 间距步进 4px；页面水平 padding 16px；卡片圆角 12px；按钮圆角 10px；点击区域 ≥44px。
- 底部 Tab：高 56px + 安全区；中央 ➕ 为 48px 圆形主色凸起按钮。
- 手势：月份左右滑、列表条目左滑出操作（编辑/复制/删除）、长按多选（P2）。

### 4.2 T3 记一笔（全屏，中央 ➕ 唤起）

```
┌───────────────────────────────┐
│ ✕                    ⋯ (选项) │
│ [支出] [收入] [转账] [还款]     │ ← 类型段控（记忆上次）
│                               │
│         ¥ 35.00          ✕   │ ← 金额显示区（40px 大字）
│    (含手续费 1.00)             │ ← 转账/含费时显示
│                               │
│ ┌───┬───┬───┬───┐            │
│ │餐饮│购物│日用│交通│ ← 一级分类宫格 │
│ ├───┼───┼───┼───┤            │
│ │ ▸午餐 │ ▸晚餐 │ …           │ ← 选中一级后展开二级横滑条
│ └───┴───┴───┴───┘            │
│ ───────────────────────────  │
│ 🏦 微信支付 ▾   📅 今天 ▾      │ ← 账户/日期快捷行
│ 💬 点击填写备注    🏷 标签      │
│ (报销 ▢)  (不计入收支 ▢)       │ ← 上下文选项
│ ┌───────────────────────────┐│
│ │ 1  2  3  ⌫               ││
│ │ 4  5  6  +               ││ ← 自研键盘：数字/./+/-/退格
│ │ 7  8  9  −               ││    右侧竖排运算列
│ │ .  0  ✓保存  再记           ││
│ └───────────────────────────┘│
└───────────────────────────────┘
```

交互规则：

- 金额键盘实时校验（两位小数、上限 9 位数）；`+`/`-` 进入算式态，行内计算。
- 转账类型：宫格区替换为"转出账户 → 转入账户"两行选择 + 手续费输入。
- 保存后 toast 1s 自动返回；"再记一笔"保留类型与账户清空金额。
- 日期选择器：今天/昨天/更多（日历）；支持补记账。

### 4.7 状态设计

- 空态：每页定制插画 + 主行动按钮（如资产页空态 = "添加第一个账户"）；
- 错误态：统一 Toast（操作类）/ 全屏重试（加载类）；
- 加载：列表骨架屏；导入大文件进度条（百分比 + 可后台）；
- 回收站：按删除时间倒序，30 天倒计时角标，支持恢复/彻底删除。

---

## 5. 深色模式与主题

- 三态：跟随系统 / 浅色 / 深色（我的→外观）；
- 主题色：内置 6 色可选（默认 `#3B82F6`），仅影响 `--brand` 及图表主色，语义色不变；
- 图表在深色下降低网格线亮度，系列色沿用语义色。

---

## 6. 响应式断点

| 宽度 | 布局 |
|---|---|
| < 768px | 单栏手机布局（基准） |
| ≥ 768px（平板/桌面） | 居中 480px "手机壳"；图表页可放宽至 720px 双栏（图表左、排行右） |
| ≥ 1280px（P2 桌面优化） | 左侧明细列表 + 右侧统计/详情 双栏 |
