## 2. PC 端布局规范（新增）

```
┌───────────────────────────────────────────────────────────────────┐
│ ● SuijiLedger    总览 / 2026年10月                🟢已同步 09:00  👤│ ← 顶栏(56px)
├──────────┬────────────────────────────────────────────────────────┤
│ 🏠 总览   │  ┌─ 净资产大卡(横向) ─────────┐  ┌─ 本月卡片 ────────┐ │
│ 📈 走势   │  │ ¥69,363.50  +4,645 (+7.2%) │  │ 账户余额+变动构成   │ │
│ 🏦 账户   │  │ 日均开销 ¥390 · 区间24天    │  │ 日均开销 ¥390/天   │ │
│ 🏷 类型   │  └────────────────────────────┘  └───────────────────┘ │
│ 🔄 数据同步│  ┌─ 资产负债总表（月份×账户矩阵，PC 专属）──────────────┐ │
│ ⚙️ 设置   │  │ 月份 │招行│基金│微信|支付宝|现金|信用卡│总资产│净资产│  │ │
│          │  │ 10月 │58.9|23.0|327|1,805|1,200|−15,868│85,231│69,363│+4,645│日均¥390│ │
│ (空)     │  │ 09月 │55.7│21.0|477|2,210|1,200|−15,868│80,586│64,718│−2,712│日均¥88 │ │
│ ┌──────┐ │  │ 08月 │…支持横向滚动、列排序、CSV 导出…               │ │
│ │＋平账 │ │  └────────────────────────────────────────────────────┘ │
│ └──────┘ │                                                          │
└──────────┴────────────────────────────────────────────────────────┘
```

- 断点：**≥1024px 双栏**（侧栏 216px 固定 + 内容区自适应）；**≥1440px** 内容区卡片流加宽，总表与走势并排；<1024px 回落手机布局（06 号稿）。
- 侧栏：分组导航（总览/走势/账户/类型管理/数据同步/设置），底部大号「＋平账」主按钮（始终可见）；当前页高亮；同步状态小圆点（绿=已同步/黄=待推送/灰=未配置/红=失败）。
- 顶栏：面包屑 + 同步状态（点击→数据同步页）+ 用户。
- **表格化平账（PC 专属）**：平账在 PC 是一张表——`账户 | 上月余额 | 本月余额(输入) | 变动`，末行合计；顶部月份与**记录日**（默认今天）选择；右上角"记几笔大项"折叠区；底部常驻预览条：`本月变动 +4,645 · 支出估算 ¥9,355 · 日均开销 ¥390（24天）`；`Ctrl+S` 保存，回车跳下一行，数字键直接录入（无虚拟键盘）。
- 快捷键：`N` 平账、`1/2/3/4` 总览/走势/账户/类型、`/` 聚焦搜索、`Ctrl+S` 保存。
- 图表在 PC 加宽（折线可 24~36 月），总表行高 40px、斑马纹、悬停行高亮、列头排序。

## 3. 手机端 · 数据同步页（我的 → 数据同步）

```
┌───────────────────────────────┐
│ ‹ 我的      数据同步           │
│ ┌───────────────────────────┐ │
│ │ 🟢 已同步                  │ │ ← 状态卡
│ │ 上次推送 今天 09:00 · 待推送 0│ │
│ │ 远程 github.com/you/mr-data │ │
│ │ [立即同步]                  │ │
│ └───────────────────────────┘ │
│ 自动规则                        │
│ ┌───────────────────────────┐ │
│ │ 平账后自动提交      [ON]    │ │
│ │ 每日 03:00 自动推送  [ON]    │ │
│ │ 备份加密(AES-256)   [ON]    │ │
│ │ 远程仓库 / 凭据        ›    │ │
│ └───────────────────────────┘ │
│ 版本历史（可恢复）      共 47 版│
│ ┌───────────────────────────┐ │
│ │ ● 平账 2026-10            │ │ ← 每条: 消息/时间/当时净资产
│ │   净资产 69,363.50  09:00 ✓│ │    + [恢复此版本]
│ │ ● 平账 2026-09 …           │ │
│ ● ● 新增类型「车贷」 …         │ │
└───────────────────────────────┘
```

交互：立即同步→转圈→toast（成功显示推送 commit 数）；点任一版本→底部弹层（该版净资产/账数 + 差异摘要 + 恢复按钮，恢复需二次确认并生成恢复提交）；红点失败态点击→冲突处理二选一（以本地为准/以远程为准）。空态（未配置）：引导卡片"三步开启：建私有仓库 → 填地址与 Token → 打开自动推送"。

## 4. 手机端 · 走势页新增「区间分析器」与日均图

```
┌───────────────────────────────┐
│ ┌─ 区间分析 ──────────────────┐│
│ │ 2026-09-30 ──→ 2026-10-24  📅││ ← 任选两个记录点
│ │ 区间 24 天                  ││
│ │ 净资产变化 +4,645  日均 +194 ││
│ │ 大项收入 +14,000            ││
│ │ 支出估算(含平账) −9,355      ││
│ │ ▶ 平均每日开销  ¥390.6      ││ ← 主指标大字
│ │ 💡 记一笔工资大项，估算更准   ││
│ └────────────────────────────┘│
│ ┌─ 日均开销（月）──────────────┐│
│ │ ▁ ▂ ▁ ▃ ▂ ▁ ▁ ▂ ▃ ▂ ▃ ▄ █  ││ ← 每月一根柱=该区间日均
│ │ 8月¥87 9月¥88 10月¥390      ││
│ └────────────────────────────┘│
└───────────────────────────────┘
```

规则：起止点从"记录点时间轴"选（非任意日期）；区间跨多月时合并计算；未记收入大项的区间，柱子半透明并标注"按资产净减少估算"。

## 6. 组件与状态增补

| 组件 | 说明 |
|---|---|
| SyncBadge / SyncStatusCard | 同步状态四态（绿/黄/灰/红），PC 侧栏与手机页共用 |
| VersionList / VersionSheet | 版本历史列表与恢复确认弹层 |
| IntervalPicker | 记录点区间选择器（时间轴刻度） |
| DailyAvgCard / DailyAvgBars | 区间指标卡 / 日均柱状图（"估算"角标规范：主指标右上角小字"估算"） |
| BalanceSheetTable（PC） | 月份×账户矩阵：粘性表头、横向滚动、列排序、导出 CSV |
| ReconcileTable（PC） | 表格化平账：输入校验同手机端、Ctrl+S、行回车跳转 |
| 侧栏 SideNav（PC） | ≥1024px 出现；移动端隐藏 |

状态：同步中（禁用立即按钮）/ 离线（黄条"离线，恢复网络后自动重试"）/ 冲突（红条+二选一）/ 未配置（引导卡）。深色模式与主题色沿用全局规范。
