## 1. 设计原则（v2 修订）

1. **每月 1 分钟**：唯一必做动作是"平账页抄余额"。任何界面都不暗示"你应该记更多"。
2. **净资产是唯一主角**：所有页面最终都在回答"我现在有多少钱、比上月多了还是少了"。
3. **平账不是错误**：差额自动生成灰色 ⚖️ 平账条目，永远让账平衡；想归因的月份才去改类型。
4. **类型极简**：默认只有「平账」，自定义类型 = emoji + 名称 + 颜色，一屏管理完。
5. 移动优先、深色模式、单手可达（沿用 v1）。

---

## 2. 核心概念与界面映射

| 概念 | 定义 | 界面承载 |
|---|---|---|
| 账户 | 资产或负债（现金/银行卡/微信/基金/信用卡欠款…） | T4 账户页 |
| 月度快照 | 某月某账户的余额，每月一批 | ➕ 平账页录入、月度详情页展示 |
| 变动条目 | 对当月余额变化的解释；Σ条目 = Σ余额变动 | 月度详情页，类型可改 |
| 平账（类型） | 内置类型 ⚖️，兜底差额自动挂它 | 全局；类型管理页不可删 |
| 结余 | 本月净资产 − 上月净资产 | 总览卡、走势页 |

**平账算法**（详见纪要 §二）：保存快照 → Δ = Σ(本月−上月) → 若有大项 S，自动补"平账 = Δ − S"；改快照 → 当月全量重算。

### 4.2 ➕ 平账页（全系统唯一录入界面）

```
┌───────────────────────────────┐
│ ✕        2026年10月 ▾     历史  │ ← 月份可改（补记任意月）
│ 状态: 待平账 · 3/6 已填         │
│ ┌───────────────────────────┐ │
│ │ 🏦 招商银行卡               │ │
│ │ 上月 55,700.00             │ │
│ │ [ 当前余额输入框  58,900▏]  │ │ ← 点击弹键盘；填过显示 ✓
│ ├───────────────────────────┤ │
│ │ 💰 基金账户  上月 21,000.00 │ │
│ │ [ 当前余额 ______ ]         │ │
│ ├───────────────────────────┤ │
│ │ 🟢 微信钱包  上月   476.50  │ │
│ │ [ 当前余额   326.50  ] ✓   │ │
│ ├───────────────────────────┤ │
│ │ 💳 信用卡欠款 上月 15,868.00│ │ ← 负债记欠款正数
│ │ [ 当前余额 ______ ]         │ │
│ └───────────────────────────┘ │
│ ▸ 记几笔大项(可选)      2笔+2,000│ ← 折叠区：工资/房贷等大项速记
│ ┌───────────────────────────┐ │
│ │ 本月变动合计    +4,645.00   │ │ ← 实时 = Σ(当前−上月)，绿涨红跌
│ │ (大项 +14,000 · 平账 −9,355)│ │ ← 已填大项时的拆分预览
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 1 2 3 ⌫ │ 未填账户自动跳转  │ │ ← 数字键盘与 v1 记账键盘同款
│ │ 4 5 6 ＋ │                   │ │
│ │ 7 8 9 − │ [保存本月快照]     │ │
│ │ . 0 ✓  [保存并看看本月变化]  │ │
│ └───────────────────────────┘ │
└───────────────────────────────┘
```

交互规则：

- 输入框获焦弹键盘；每填完一个账户自动滚动到下一个未填项；
- "记几笔大项"：+ 添加条目（选类型 → 金额 → 备注），最多建议 5 笔；系统实时显示"平账差额预览"；
- 保存 = 一批快照 + 自动生成变动条目（大项 + 兜底平账）；保存后 toast 并跳转月度详情；
- 改历史月份：直接覆盖该月快照，之后各月**不重算**（历史就是历史），但当月条目与统计重算；
- 首月平账：无上月余额，所有输入即基准值，变动合计为 "—"。

### 4.4 T2 走势页

- 净资产折线（12/24/36 月切换，点某点 → 该月详情）；当前值徽标；
- 月度结余柱状图（绿正红负，切年视图显示年度结余大数）；
- 资产配置环形图（各资产账户占比，负债以"−"区块显示）；下方账户排行；
- 类型累计贡献条形（如 工资累计 +96,000 / 平账累计 −38,533），可切换时间范围。

### 4.5 T4 账户页

- 顶部净资产摘要（总资产 / 总负债 / 净资产）；
- 分组列表：资产组（现金与储蓄 / 网络资产 / 投资…）、负债组（信用卡 / 贷款…），组可自定义；
- 账户行：emoji 图标、名称、当前余额（来自最近快照）、最近 3 月迷你条形；
- 账户详情页：历史余额表（月 | 余额 | 变动）、编辑/归档（归档保留历史，不再出现在平账页）；
- + 添加账户：名称 / emoji / 资产或负债 / 初始余额（即首个快照）/ 是否计入净资产 / 分组。

### 4.6 T5 我的页 + 类型管理

- 类型管理（新核心设置）：
  - ⚖️ 平账 —— 系统内置，不可删除（角标"内置"），可改颜色；
  - 自定义类型列表：emoji + 名称 + 使用次数，编辑/删除（删除时其历史条目回退为"平账"）；
  - + 新建类型：emoji 选择器 + 名称 + 颜色，一步完成；
- 其余入口：导入钱迹账单（→ 自动生成历史快照向导）、导出（快照矩阵 CSV / 钱迹 19 列 CSV / 全量 JSON 备份）、平账提醒设置（每月 N 号 + 浏览器通知开关）、回收站、外观（深色/主题色）、安全（口令）、关于。

### 4.7 钱迹导入向导（生成历史快照）

```
①选来源(钱迹导出文件) → ②上传解析 → ③预览 → ④完成
预览内容：
  解析账单 12,847 笔 · 识别账户 6 个 · 覆盖 2023-01 ~ 2026-09
  将生成 45 个月度快照
  ┌ 月份      净资产      (由账单重放得出)
  │ 2023-01   ¥31,204.00
  │ 2026-08   ¥66,800.00
  │ 2026-09   ¥64,718.50   ← 与你手动平账衔接
  └ [确认生成快照] [同时保留逐笔账单(可选存档)]
```

衔接规则：导入的快照月与已有手动快照冲突时，**手动数据优先**，导入值仅填充空缺月份。

### 4.8 状态与引导

- **首次使用**（三步引导）：欢迎页（讲清"每月 1 分钟"理念）→ 添加账户（含初始余额）→ 设提醒日 → 总览空态"去完成第一次平账"；
- 平账提醒：到提醒日本月无快照 → 总览顶部黄条 + PWA 通知（文案平和不焦虑："月底了，花 1 分钟对个账"）；
- 月度详情空月（跳记的月份）：显示"该月无快照"，走势曲线断点连接并淡化，点击可补记；
- 回收站：删除快照/大项条目进回收站 30 天。
