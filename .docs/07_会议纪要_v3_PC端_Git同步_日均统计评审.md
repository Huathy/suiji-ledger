## 一、需求①：Git 自动同步数据（PM 提案 / Arch 方案 / BE 实现）

**目标**：数据多一份异地版本化保险——每次平账自动生成版本，自动推送远程仓库；任何一次误操作都能回到任意历史版本。

**方案决议**：

1. 数据卷 `/data` 初始化为 **Git 仓库**（后端内置 `isomorphic-git`，无外部依赖），跟踪对象为每次平账后生成的**全量备份 JSON**（快照化文本，diff 友好）；SQLite 主库不入库（二进制无 diff 价值）。
2. **自动提交**：每次平账/修改类型/导入完成后自动 commit，提交消息模板 `chore(data): 平账 2026-10 · 净资产 69,363.50`。
3. **自动推送**：可配置远程（GitHub/Gitea/自建，PAT 或 SSH）；策略三选一：每次提交后立即 push / 每日定时 push / 仅手动。默认每日 03:00（备份任务之后）。
4. **版本恢复**：提交历史列表（时间 + 消息 + 当时净资产）→ 任选一版"预览差异 / 恢复此版本"（恢复 = 用该版备份 JSON 走现有恢复流程，生成一条恢复 commit，历史不丢）。
5. **隐私**：备份 JSON 提交前可选 **AES-256-GCM 加密**（密钥仅存本地配置，不入库不推送）；远程仓库建议私有。
6. **冲突**（多设备同写）：push 失败时提示，二选一"以本地为准（强推）/ 以远程为准（拉取覆盖本地）"；v1 产品阶段按单写多读设计，家庭多写为 P2。
7. UI：我的 → **数据同步**页（状态卡 / 规则开关 / 提交历史 / 立即同步 / 恢复版本）；PC 端侧栏常驻同步状态点。

## 二、需求②：PC 端（FE 主导）

1. 形态：**响应式 Web 桌面布局**（≥1024px 启用），不做 Electron——PWA 本身可安装到 Windows/macOS 桌面，后续有原生壳需求再评估。
2. 布局：**左侧导航栏**（总览/走势/账户/类型管理/数据同步/设置 + 底部大号「平账」按钮）+ 右侧内容区；月度详情/账户详情以**右侧面板或独立页**呈现。
3. PC 专属视图（移动端不给）：
   - **资产负债总表**：月份 × 账户矩阵（行=月份倒序，列=各账户 + 总资产 + 净资产 + 结余 + 日均开销），懒人记账在 PC 上最实用的形态；
   - **表格化平账**：PC 的平账就是一张表——账户 | 上月余额 | 本月余额（输入框）| 变动，底部合计与日均预览，回车跳行、Ctrl+S 保存。
4. 快捷键：`N` 平账、`1/2/3/4` 切页、`/` 搜索；数字直接可用键盘录入（不弹虚拟键盘）。
5. 宽度阶梯：≥1024 双栏；≥1440 内容区可同时展示总览+总表（三栏卡片流）。

## 三、需求③：两次记录区间内的平均每日开销统计（SA 定义）

**模型调整**：`MonthlySnapshot` 增加 `recordDate`（该次平账的实际日期，默认当天，可改；此前按月末补齐）。"区间"= 相邻两次记录的 `recordDate` 之差；支持跳月（如 8 月忘记，8-31→10-24 为一个区间）。

**统计口径（会议确认）**：

```
区间天数           = recordDate(本期) − recordDate(上期)      （同日两次记为 1 天）
净资产变化 Δ       = 本期净资产 − 上期净资产
大项收入合计 I      = 区间内类型属于「收入性质」的大项条目（工资/投资收益等，类型带收支方向标记）
支出估算 S         = I − Δ        （未记任何收入大项时 S = −Δ，即按"资产净减少"估计，UI 标注"估算"）
平均每日开销       = S / 区间天数
日均净结余         = Δ / 区间天数
```

语义要点：平账模型的"开销"只能**估算**——收入没记就会低估支出。因此文案一律带"估算"，并引导"想让日均更准，记一笔工资大项即可"。

**展示位置**：

1. 总览月度卡片尾部常驻一行：`日均开销 ¥390 · 区间 24 天`；
2. 月度详情页新增"区间统计"卡（区间日期/天数/大项收入/支出估算/日均开销/日均净结余）；
3. 走势页新增**区间分析器**：任选两个记录点 → 上述全套指标；另增"日均开销"月度柱状图；
4. PC 资产负债总表直接带"日均开销"列。

**示例对账**（视觉稿数据）：9-30 → 10-24 共 24 天，Δ=+4,645，I=+14,000（工资 12,000+投资 2,000）→ S=9,355 → **日均 ¥390/天**，日均净结余 +¥194。
