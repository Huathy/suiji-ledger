## 二、钱迹导入（M3）

**流程**：我的 → 导入钱迹账单 → 选文件（.xlsx 推荐 / .csv，GBK 自动回退）→ 解析预览（账单数/账户/月份范围/将生成快照数/跳过原因）→ 每账户设置性质与期初余额 → 确认导入 → 生成月度快照 → 看走势。

**实现**：
- `apps/web/src/import/qianji.ts`：19 列格式解析（列规格来自 `.history/02` §5）+ 按账户逐月重放聚合器（CSV 自带解析器保持日期原样；SheetJS 仅用于 xlsx 且加 dateNF 防美式日期；已报销/报销包聚合行自动跳过防重复计算；优惠券冲减支出、手续费计入转出）
- 提交接口双模式：服务端 `POST /api/import/snapshots`（months.service）+ 离线 localHandle 同路由；**手动记录优先**——已存在的 (月,账户) 快照不覆盖，只填空缺月
- 快照 recordDate = 各月末，逐月填充至全局最后月（保证任意月份净资产完整）
- WebView 文件支持：MainActivity 增加 `onShowFileChooser`（APK 内 `<input type=file>` 可用）

## 四、已知限制

- 仅生成月度快照，不保存逐笔明细（设计如此，见导入页说明）
- 债类账单（借入/借出/收款/还款/利息）按近似符号规则映射到账户1，导入后可在预览核对各账户月余额
- xlsx 单元格日期经 SheetJS 格式化存在理论上的时区边缘情况（月末 00:00-07:59 记录），建议以 xlsx 原生 yyyy-mm-dd 格式导出
- 服务端模式测试时发现 curl/Git Bash 中文请求体会 mojibake（环境问题非应用问题），接口测试统一用 Node fetch
